# AI-ML-Interview-Questions — Contribution Guide

Welcome — this folder holds interview-style AI/ML Q&A contributions. Thank you for helping improve this resource.

How to contribute
- Add new Q&A entries to `AI_ML_Interview_Questions.md` or create separate files (`01.md`, `02.md`, ...). Keep files small and reviewable.
- Each question entry should include:
  - Question (heading)
  - Short answer (1–3 lines)
  - Optional 1–3 line explanation or example
  - Optional reference link for deeper reading
- Prefer concise, clear wording. Keep technical accuracy and add references for claims.

PR checklist
- [ ] At least one contributor name in the file header.
- [ ] Each Q&A formatted consistently.
- [ ] Add references for non-trivial answers.
- [ ] Include `Closes #<issue-number>` in the PR body if you're addressing an open issue.

Review guidelines for maintainers
- Prefer small PRs (5–25 Q&A) for easier review.
- Check references and clarity; please suggest edits inline.

If you'd like, break very long answers into separate explanation files and link them from the main Q&A.

Thanks for contributing!
