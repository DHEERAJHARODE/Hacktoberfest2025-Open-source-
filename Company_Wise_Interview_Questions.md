## Google

### Algorithms & Data Structures
1. **Two Sum Problem**: Given an array of integers, return indices of the two numbers such that they add up to a specific target.
2. **Longest Substring Without Repeating Characters**: Find the length of the longest substring without repeating characters.
3. **Binary Tree Maximum Path Sum**: Find the maximum path sum in a binary tree.
4. **Median of Two Sorted Arrays**: Find the median of two sorted arrays.
5. **LRU Cache Implementation**: Design and implement a data structure for Least Recently Used (LRU) cache.

### System Design
1. Design a URL shortening service like bit.ly
2. Design Google Maps
3. Design a distributed cache system
4. Design YouTube

### Behavioral
1. Tell me about a time you had to work with a difficult team member.
2. Describe a situation where you had to make a decision with incomplete information.

## Amazon

### Algorithms & Data Structures
1. **Two Sum (variants)**: Various versions including sorted arrays and finding all pairs.
2. **Merge K Sorted Lists**: Merge k sorted linked lists and return it as one sorted list.
3. **Number of Islands**: Count the number of islands in a 2D grid.
4. **Rotting Oranges**: Find minimum time required to rot all oranges.
5. **Critical Connections in a Network**: Find all critical connections in the network.

### System Design
1. Design Amazon's product recommendation system
2. Design a distributed key-value store
3. Design Amazon's inventory management system
4. Design a rate limiter

### Leadership Principles (Behavioral)
1. Customer Obsession: Tell me about a time you went above and beyond for a customer.
2. Ownership: Describe a project you owned from start to finish.
3. Invent and Simplify: Give an example of a complex problem you simplified.
4. Dive Deep: Tell me about a time you had to deep dive into data to solve a problem.

## How to Contribute

We welcome contributions! Here's how you can help:

### Adding New Questions
1. **Fork this repository**
2. **Add questions** under the appropriate company section
3. **Follow the format**: 
   - For coding questions: Include problem name and brief description
   - For system design: Include the system to be designed
   - For behavioral: Include the question or scenario
4. **Create a pull request** with a clear description

### Adding New Companies
To add a new company:
1. Create a new section using the format: `## Company Name`
2. Add subsections for different question types (Algorithms, System Design, Behavioral)
3. Add the company to the Table of Contents
4. Maintain alphabetical order

### Scalable Structure
This document follows a clear hierarchy:
- **Level 1**: Company Name (## heading)
- **Level 2**: Question Category (### heading)
- **Level 3**: Individual questions (numbered list)

This structure allows for:
- Easy navigation via Table of Contents
- Quick addition of new companies
- Simple organization of questions by type
- Scalability as the repository grows

### Quality Guidelines
- Ensure questions are from actual interviews or credible sources
- Keep descriptions concise and clear
- Avoid duplicate questions within the same company section
- Update the Table of Contents when adding new companies
